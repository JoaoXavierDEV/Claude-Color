# Segurança

Se você encontrar uma falha de segurança no Claude Color, **não abra uma issue pública**.

Reporte de forma privada pela aba **Security → Report a vulnerability** deste repositório (GitHub Security Advisories). Descreva o problema, como reproduzir e o impacto. A resposta vem assim que possível, e a correção é publicada numa nova versão com o devido crédito, se você quiser.

Apenas a versão mais recente recebe correções.
